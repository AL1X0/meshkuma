Notifications sur téléphone (ntfy)

Gratuit, sans inscription, fonctionne instantanément sur iPhone et Android.

  1. Installez l'application gratuite ntfy sur votre téléphone (App Store ou Google Play).
  2. Cliquez sur Créer un canal privé puis abonnez-vous à ce nom dans l'application ntfy.
  3. Cliquez sur Envoyer une alerte de test en haut pour vérifier la réception.

Messages iMessage (Photon)

Compatible avec Photon Cloud (app.photon.codes) et Photon HTTP Proxy (serveur Mac).

  1. Sur app.photon.codes (Stable) ou app.beta.photon.codes, ouvrez votre projet puis copiez son Project ID et son Project Secret / Clé API.
  2. Sur une ligne partagée (Free / Pro), MeshWatch inscrit automatiquement votre numéro dans l'onglet Users du projet lors du premier envoi (vous pouvez aussi le gérer dans app.photon.codes → Users).
  3. Indiquez vos identifiants et votre numéro ou email Apple ci-dessous (MeshWatch détecte automatiquement la bonne version Photon).
